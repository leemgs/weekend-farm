사진 저장소 관리

1. GitHub 연결

이 저장소에 Contents: Read and write 권한이 있는 fine-grained token을 입력하세요. 토큰은 현재 브라우저 탭의 sessionStorage에만 보관되며 저장소에 기록되지 않습니다.

2. 사진 관리

분류와 연도를 선택하면 사진 파일이 docs/photos/분류/연도/에 저장됩니다. 각 작업은 GitHub의 단일 커밋으로 기록됩니다.
