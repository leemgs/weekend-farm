사진 저장소 관리

1. GitHub 연결연결됨

이 저장소에 Contents: Read and write 권한이 있는 fine-grained token을 입력하세요. 토큰은 현재 브라우저 탭의 sessionStorage에만 보관되며 저장소에 기록되지 않습니다.

2. 사진 관리

분류를 선택하면 자동 감지 상태에서도 모든 연도의 기존 사진과 수정·이름 변경·삭제 버튼이 아래에 표시됩니다. 새 사진의 연도는 EXIF 촬영일, 파일명, 파일 수정일 순서로 감지하며, 수정할 때는 사진과 저장될 파일명을 함께 바꿀 수 있습니다.
